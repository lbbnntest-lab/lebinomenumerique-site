Ajouter un service

En préparation

Votre adresse de réception est en cours de préparation par notre équipe. Vous recevrez un email dès qu'elle est prête (généralement sous 24h ouvrées).

C'est vers cette adresse que vous redirigez (ou faites suivre) les emails à traiter.

Comment connecter votre boîte

  1. Dans les réglages de votre messagerie, ajoutez une redirection (ou « transfert ») vers l'adresse ci-dessus.
  2. Si votre fournisseur demande une confirmation (Gmail envoie un code à l'adresse), pas d'inquiétude : nous recevons ce code et le validons pour vous sous quelques minutes. Si ça bloque plus de 30 min, écrivez-nous.
  3. Envoyez-vous un email de test depuis une autre adresse — il doit apparaître dans « Mes demandes » de votre espace en une minute.

Instructions par fournisseur

Gmail / Google Workspace
Paramètres (roue crantée) → Voir tous les paramètres → onglet Transfert et POP/IMAP → Ajouter une adresse de transfert → collez l'adresse → Gmail envoie un code de confirmation (nous le validons pour vous) → une fois confirmé, cochez Transférer une copie du courrier entrant.
Outlook / Microsoft 365
Paramètres → Courrier → Transfert → activez Activer le transfert → saisissez l'adresse → Enregistrer. (Outlook ne demande pas de confirmation.)
OVH / Gandi / autre (cPanel, Zimbra…)
Cherchez « Redirection » ou « Filtres » dans l'interface de votre messagerie ou de votre hébergeur, et ajoutez une redirection de votre adresse pro vers l'adresse ci-dessus. En cas de doute, envoyez-nous le nom de votre fournisseur, on vous guide.
